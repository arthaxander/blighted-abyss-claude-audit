Сценарий

Проклятия на входе с предыдущих этажей (0 = нет). Алтарь предлагает два случайных допустимых проклятия. Приоритет выбирается только среди предложенных; иначе повышаем уже взятое, при равенстве — первое. Finder сохраняет эти условия для всех билдов.

Полная зачистка выбранной ветки. Рыбалка, смена найденной экипировки и эвакуация пока не моделируются.

Дополнительные настройки необязательно

Build Finder

Оптимизирует шанс пройти маршрут и победить босса. Ищет Top 3–5 для выбранного класса, профиля и локации. Поиск ступенчатый: это лучшие найденные кандидаты, а не полный перебор всех сочетаний.

Отметь, что разрешено менять. Остальные части выбранной сборки сохраняются. Финальная проверка использует новые общие seed.
